# Mac 文档导入

入口：添加 → 导入文档。TXT、TEXT、Markdown、CSV 只需普通文本模型；PDF/Word 图文导入需在设置中配置 支持图片输入的 OpenAI-compatible 模型，并勾选「此模型支持图片输入」；该选项是用户能力声明，不是自动检测。

## 使用流程

1. 选择或拖入 PDF / DOCX / TXT / TEXT / Markdown / CSV。文本按空行分段，CSV 按记录读取（UTF-8，允许 BOM，表头非空且唯一，列数一致）。PDF/Word 本地渲染整页图片并提取可用文字，显示可选择的页面；支持没有文字层的扫描 PDF 和仅含图片的 Word。原文件不上传。
2. 选择范围、目标词条数（1–50）、是否生成反向卡和生成要求。点击开始后才把所选页面图片和文字通过标准 `image_url` + `text` 消息发送至已配置模型。
3. 按页提取候选；图像引用是模型转录结果，审核时需对照页面图片核对（旧纯文本任务继续进行原文包含校验），再逐条生成正反向草稿。跨段按词条去重，审核时请核对卡片库中的已有词条。
4. 在「任务队列」逐张审核正向／反向卡，支持编辑草稿、单张确认和丢弃；不支持批量确认。暂停保留已完成部分，失败任务可继续。
5. 已接受卡片进入现有卡片库、学习调度和同步。草稿不会影响学习数量。

## 重新生成与存储

审核页的「重新生成草稿」提交独立后台任务，携带当前这一张卡片、用户要求、原文上下文、位置和页面图片（如有），只更新该方向。生成成功前保留旧稿；期间的编辑、确认、丢弃会使旧请求失效。

统一队列保存于 `~/.vword/ai-tasks.json`，不保存 API Key，不进入同步文件夹。页面图片仍使用 `~/.vword/document-images/` 中的本机引用。旧 `document-imports.json` 首次打开迁移为逐卡任务，已入库 ID 和来源保留。重启后任务暂停，继续时跳过已保存的分析与生成结果。

确认使用固定草稿 ID 和正式事件提交凭据，重试不会重复卡片、统计、进度或恢复删除卡片。完整行为见 [AI 任务队列](AI-TASK-QUEUE.md)。

## 首版边界

- Mac 13+；浏览器显示需要 Mac 的说明。
- PDF 使用 PDFKit 渲染整页（长边 1800 像素）；DOCX 按 Office Open XML 中的文字/内嵌图片顺序读取，使用 TextKit 排版为 A4 图文页（1190×1684），保留内嵌图片。Word 分页可能与原软件不同，复杂浮动布局建议另存 PDF。旧 `.doc` 需先转换。
- 限制 20 MB、30 万提取字符、100 页、每份文档渲染图片总量 100 MB。无文字页也发送整页图像；加密、损坏或无法分页的文档拒绝继续。
- 新导入按完整页面分析，不切开或合并页面图像。旧纯文本草稿兼容原有 6000 字符分段、500 字符重叠。目标数量是上限，不保证凑满。
- 同一文档内部依次分析／生成；所有 AI 来源共享最多 3 个并发任务。模型请求 180 秒超时，生成期间可审核已完成的卡片。
- 设置中启用的图片生成不用于文档导入；此流程生成文本卡片。

## 验证

- `node scripts/test-document-import.mjs`：上下文引用校验、分段、断点继续、失败重试、完整重新生成请求、取消保留、草稿隔离、接受保护、保存失败。
- `bash src-tauri/macos/test.sh`：真实 PDF/DOCX 图文夹具、仅含图片的 Word 像素校验、扫描 PDF、空页/加密/损坏/超限、入库幂等性及删除保护、本机草稿不进入同步事件。
- `npm run build` 与 `cargo check --manifest-path src-tauri/Cargo.toml --offline`。
- 浏览器使用隔离的原生桥接和模型夹具联调真实 React 页面；未使用用户的真实文档或 API Key 调用外部模型。

## App 内帮助与直接导入

「设置 → 帮助 → 帮助与导入格式」及「添加 → 帮助与导入格式」包含可下载的 CSV / JSON 示例与字段要求。

「添加 → 导入卡片 CSV / JSON」用于直接入库，不调用模型。CSV 必须包含 `id,front,back`，可选 `example,createdAt`；列顺序不限，区分大小写，未知列拒绝。每条记录代表一张卡片，不自动生成反向卡。CSV 最多 20 MB / 100000 条，复用 JSON 的字段和重复 ID 校验及更新规则。相同 ID 更新已有卡片并保留学习进度，删除过的 ID 不可重用。

CSV 使用英文逗号；含逗号、双引号或换行的字段用双引号包围，内部双引号写成两个双引号。`createdAt` 是非负 Unix 秒数，留空即省略。示例：`docs/formats/cards.example.csv` 与 `cards.example.json`。

普通业务 CSV 作为 AI 学习材料时可用任意表头；TXT/CSV 均不需要图片模型。帮助文档明确区分这两条入口。
