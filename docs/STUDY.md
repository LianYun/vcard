# 复习增强与提前学习

2026-10-04。页面参考通过 OpenDesign 的 Local Codex 流程生成的 `design/study-expansion.html`，沿用现有紫色、白灰底、固定评分区和手机分段选择。

## 功能入口

- 卡片页 → 提前学习：选择 1–5 天，预览日期范围、匹配数量和前 5 张卡片。
- 卡片页 → 学习数据：今日学习张数/评分次数、近 7 天评分分布和遗忘率、未来 7 天当前到期量、近期难词。
- 卡片页 → 快速学习：按标签、到期、新卡、标记、最近 7 天忘记/新增筛选，每轮 10/20/50 张；不评分、不修改进度或每日额度。
- 学习页 → 学习工具：今天跳过、暂停、标记、编辑、学习详情；撤销最近一次本会话评分。
- 卡片管理 → 状态筛选；卡片操作可恢复暂停或取消标记。
- 备份与恢复：本机每日自动快照、手动备份、恢复前预览与确认；恢复前额外备份当前数据。

## 提前学习的准确范围

选择 N 天意味着：**明天 ≤ 原到期日 ≤ 今天 + N 天**，包括两端。例如 10 月 4 日选择 3 天，范围是 10 月 5–7 日。

只选择已实际学习过的卡片；排除当天/过期任务、新卡、暂停、今天跳过、正在分钟级重学的卡片。排序按到期日然后卡片 ID。没有匹配卡片时禁止开始。评分计入正式复习，按实际评分日计算新到期时间；不领取新卡、不消耗新卡预算。不会把“今天加 N 天”当作评分日期。

## 新卡、重学与关联卡

新建时的空进度不再代表已学习。领取事件/issuedAt 标记新卡已进入学习，额度跨标签共享；未完成但已领取的卡可继续学习。

- 新卡/学习中：重来 1 分钟，困难 6 分钟，良好推进至 10 分钟；完成 10 分钟步骤后进入长期复习。简单直接进入长期复习。
- 已学卡：重来进入持久化重学，重置长期连续成功次数；完成短间隔后继续 SM-2。其余评分复用 SM-2。
- 时间以毫秒时间戳保存分钟级到期；长期到期和额度日期仍采用本地日历。关闭/重启不会丢失等待中的卡片。
- 新生成的双向词卡带 noteId；复习其中一张会将另一张延后到次日。既有无关联卡不做文本猜测配对。撤销对应评分也会解除自动关联延后。
- 评分按钮预览与实际评分使用同一计算函数。

## 历史、撤销与同步

新评分记录包含事件 ID、评分档位、评分前后状态、实际时间及算法版本。旧版缺失的档位不推断；统计界面明确提示详细评分记录从本次升级开始，原累计活动记录保留。

Mac/iPhone 继续使用共同 Swift 投影及 JSON 事件存储。撤销追加引用原评分的事件；只有该卡最新有效评分可以撤销。遇到另一端后续评分，拒绝撤销；合并时同样按确定顺序验证。已撤销记录不计入评分统计。

事件文件写入版本升级至 **2**，可读历史版本 1。旧客户端不能理解新状态，请把使用同一同步目录的 Mac/iPhone 一起升级。Watch 新传输协议也为 2；本机旧版缓存保留卡片和待回传记录后迁移，不能让旧 Watch 继续产生旧规则评分。真实 iCloud 上传/下载及配对 Watch 后台传输仍需要真机验收。

浏览器/Android 在 storage.ts 中以单个 `vibe-word:study:v2` 文档保存评分、进度覆盖、状态及额度；串行写入，支持 Web Locks 时跨标签页互斥。旧进度和统计在读取时合并。组件不直接访问 localStorage。

## 备份

Mac/iPhone 每个发生写入的本地日期保存首次写入前的事件快照，自动保留最近 14 个这样的日期；手动备份不自动删除。完整本机备份包含历史配置；它不是用于公开分享的卡片导出。

恢复会保留旧事件文件，通过一个恢复事件建立新的投影基线，可以恢复曾被墓碑删除的卡片及历史。Mac/iPhone 的恢复会同步到其他设备，因此界面要求先同步全部设备。恢复后应停止旧设备离线编辑并检查各端结果。

浏览器/Android 备份保存在同一应用存储区域，清除应用数据也会清除备份；恢复有持久化标记，可在下次启动继续完成中断的键写入。备份配额不足会报错，不伪装保存成功。非 Mac 的旧 SQLite 桌面后端目前不支持完整备份，入口明确提示；本次主要验收覆盖 Web、Mac 原生存储与 iPhone。

## 当前卡片重新生成（2026-10-08）

学习页「… → 重新生成」打开选填要求弹窗。生成仅产生内存草稿，显示正反面 Markdown 和更新后的例句；返回修改会保留要求，关闭或取消生成不写入卡片。只有预览页点击「确定」才替换内容，成功后当前卡片回到正面。

Web、桌面、Android 共用 React 弹窗，iOS 使用原生 Sheet。模型使用设置中的文本模型，不新建卡片或关联卡、不重置学习进度。保存保留 ID、标签、牌组、noteId、创建时间及历史；重新读取后校验原内容，已删除或内容发生变化则拒绝覆盖。原生端在存储事务中校验并写入。Anki 模板卡暂不支持此入口，请使用笔记编辑。

设计稿：`design/card-regeneration.html`；实际页面截图：`design/card-regeneration-implemented.png`、`design/card-regeneration-mobile-implemented.png`。回归：`node scripts/test-card-regeneration.mjs`、`scripts/test-card-regeneration-browser.cjs`（模拟模型响应）、Swift `CardRegenerationTests`、macOS bridge storage 测试。
